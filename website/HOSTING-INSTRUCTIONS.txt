HOW TO UPLOAD (cPanel / shared hosting)
---------------------------------------
1. Unzip the file on your computer.
2. In cPanel, open File Manager and go to the  public_html  folder
   (or the folder for this domain).
3. Upload EVERYTHING from the unzipped folder into public_html, keeping the
   folder structure exactly as it is (the "assets" folder must stay next to
   index.html). Do not upload the outer folder itself, only its contents.
4. Make sure there is no other index.html / index.php left in public_html
   from the hosting company's default page.
5. Turn on free SSL (HTTPS): cPanel > SSL/TLS Status > Run AutoSSL,
   or Let's Encrypt, depending on the host.
6. Optional: once HTTPS works, open the ".htaccess" file and remove the "#"
   in front of the three "force HTTPS" lines so all visitors use https://.
   (".htaccess" is a hidden file; enable "Show hidden files" in File Manager.)

HOW TO UPLOAD (Netlify — easiest free option)
---------------------------------------------
1. Go to app.netlify.com/drop and drag the unzipped folder onto the page.
2. Netlify > Domain management > Add a domain > enter the domain and follow
   the DNS instructions it shows (or point the domain's nameservers to Netlify).
   HTTPS is turned on automatically.
